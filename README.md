# Pass, Fail, or Inconclusive? Regression Testing of Fine-Tuned LLM Updates with Small Test Suites

Replication package for the paper. It contains the per-test outputs and the scripts that reproduce every number in the paper. No GPU and no database are needed.

## What is inside
| Path | Content |
|---|---|
| `reports/retention/c1_eval_slice.json` | Regression suite: 100 pinned prompts (test set C1) |
| `reports/retention/c2/c3/c4_eval_slice.json` | 100-prompt test sets of later checkpoints |
| `reports/retention/heldout_slice.json` | 300 held-out prompts (H) |
| `reports/retention/matrix_raw.json` | 3,500 per-test outputs and scores (Base, C1–C4 on every test set) |
| `reports/retention/matrix_summary.json` | Suite scores per version and test set |
| `reports/retention/replay_comparison.json` | Summary of the second test setup (used in RQ3) |
| `reports/retention/gate_decisions.json` | Gate decisions with bootstrap intervals |
| `reports/tables/paper2_regression/` | Tables I–IV as Markdown |
| `02_distillation/evaluation_suite/06_eval_metrics.py` | Rule-based scoring code (no LLM judge) |
| `scripts/recompute_perquery.py` | Re-scores all stored outputs; adds task success and faithfulness |
| `scripts/paper_numbers.py` | Computes all numbers in Tables II–IV and RQ1–RQ3 |
| `scripts/gate_check.py` | Three-outcome release gate (pass / fail / inconclusive) |
| `02_distillation/retention_and_replay/eval_retention_matrix.py` | Reference: how the outputs were generated (needs GPU and database) |
| `02_distillation/incremental_pipeline/12_train_incremental.py` | Reference: how versions C1–C4 were trained (needs GPU and database) |
| `models/gemma-ckpt*-lora/adapter_config.json` | LoRA settings (r = 16, alpha = 16) |

Data: instructions and reference outputs come from the Stanford Alpaca dataset (outputs generated by text-davinci-003).

## Reproduce the paper (CPU, under a minute)
```bash
pip install -r requirements.txt
python scripts/recompute_perquery.py
python scripts/paper_numbers.py
python scripts/gate_check.py --matrix reports/retention/matrix_raw.json --out reports/retention/gate_decisions.json
```
Expected key lines from `paper_numbers.py`:
- `C2_vs_C1: R 0.9729 CI [0.9336, 1.0093] P 0.632 ... dec INCONCLUSIVE`
- `AGGREGATE-ONLY ... +0.0047 ... +0.0014 ... +0.0191`
- `SETUP C2 matrix 0.558980 vs second setup 0.5554 diff -0.0036 share 0.31`

## Method in short
- Score per test: mean of seven rule-based measures × (1 − hallucination rate). ROUGE/BLEU are reported but not part of the score.
- Relative score R = new suite score / deployed suite score; fixed rule: release if R ≥ 0.98.
- Proposed gate: 10,000 paired bootstrap resamples → 95% interval of R. Pass if the whole interval ≥ 0.98, fail if it is below 0.98 (or a functional/hallucination check fails), otherwise inconclusive.
- Tests: Wilcoxon signed-rank (primary), paired t-test, Benjamini–Hochberg over nine metric rows.
