\begin{abstract}
Streaming fine-tuning can raise aggregate scores while degrading behaviors learned from earlier data, yet software delivery pipelines rarely gate adapter promotion on behavioral contracts. We examine this problem in INTUNE, an event-driven distillation pipeline that produces sequential LoRA adapters for a compact language model. Across longitudinal evaluation, macro scores rise from 0.4020 to 0.5073, while 23.2\% of evaluated queries exhibit localized regression; checkpoint-level tracking confirms statistically significant performance decay on earlier cohorts ($p < 0.05$ on lexical fidelity, $p = 0.0224$ across long horizons). We formulate backward retention relative to an accepted adapter and use a cross-checkpoint matrix to expose retention decay. We present a deployment gate for streaming updates that evaluates candidate weights against pinned behavioral and operational contracts before promotion, preserves the incumbent adapter upon contract failure, enforces cryptographic candidate-hash binding with atomic durable promotion, and enables replay-based remediation. Empirical validation on a 100-example canary demonstrates that the gate reliably traps silent regressions and promotes remediated adapters with verified zero-downtime serving.
\end{abstract}

\begin{IEEEkeywords}
Software Engineering for AI, continuous integration, design by contract, circuit breaker, knowledge distillation.

\section{Introduction}
Continuous integration and delivery make a software release conditional on automated tests. Machine-learning production guidance likewise emphasizes tests and monitoring, but learned behavior is harder to specify than ordinary input/output invariants \cite{NIPS2015_86df7dcf,8258038,8804457}. Streaming distillation adds a further complication: a new adapter may improve performance on recent examples while changing answers on historical ones. A pipeline that accepts weights solely because training completed or an aggregate score rose therefore lacks an explicit behavioral acceptance boundary.

INTUNE is an event-driven continuous-distillation system in which database change events pass through Kafka and Spark Structured Streaming to dispatch incremental model updates \cite{bharuka2026intune,kreps2011kafka,180560}. LoRA and quantized LoRA provide parameter-efficient adaptation mechanisms; knowledge distillation transfers teacher behavior to a smaller student \cite{hu2022yelong,NEURIPS2023_1feb8787,hinton2015distilling}. These mechanisms support frequent updates, but do not themselves decide whether an updated adapter is safe to serve.

The longitudinal distillation progression reveals a critical paradox: while macro performance improves monotonically from 0.4020 to 0.5073, 23.2\% (4,588 of 19,810) of evaluated queries exhibit localized regression relative to their immediate predecessor. Furthermore, cross-checkpoint evaluation shows that performance on the earliest cohort slice (C1) drops from 0.5746 to 0.5590 after training on subsequent stream batches. These empirical observations demonstrate that aggregate progress and cohort retention represent distinct operational dimensions: continuous adaptation can steadily improve overall benchmarks while silently degrading competence on earlier interaction distributions.

We present a prototype deployment gate for streaming adapters. It evaluates candidates against pinned historical and operational contracts before promotion, retains the currently accepted adapter on failure, and requires replay-patched candidates to pass the same gate. Our contributions are: (1) a cohort-relative formulation of backward retention and empirical evidence of the continuous fine-tuning paradox; (2) a three-tier contract gate architecture featuring cryptographic candidate-hash binding, crash-consistent atomic promotion, and a release finite state machine; and (3) an empirical evaluation and statistical significance analysis demonstrating automated regression detection and replay-based remediation. Unlike continual-learning algorithms that modify optimization to reduce forgetting, the proposed contribution is a release decision mechanism complementary to training-time methods \cite{NIPS2017_f8752278,kirkpatrick2017overcoming,8107520}.

\section{Continuous Fine-Tuning Paradox and Problem Formulation}
\subsection{Aggregate and per-query behavior}
Let $\mathcal{D}_i$ be the evaluation cohort associated with stream checkpoint $i$, and let $C_t$ be the adapter after training through checkpoint $t$. For a fixed evaluation protocol, let $s(C_t,x)\in[0,1]$ be the score for query $x$. The cohort score is
\begin{equation}
S(C_t,\mathcal{D}_i)=\frac{1}{|\mathcal{D}_i|}\sum_{x\in\mathcal{D}_i}s(C_t,x).
\label{eq:cohort}
\end{equation}
For a reference adapter $C_{t-1}$ and evaluated query set $\mathcal{Q}$, define the fraction of queries regressing by more than tolerance $\epsilon$ as
\begin{equation}
\rho_t(\epsilon)=\frac{1}{|\mathcal{Q}|}\sum_{x\in\mathcal{Q}}\mathbb{I}[s(C_t,x)<s(C_{t-1},x)-\epsilon].
\label{eq:regression}
\end{equation}
Equation~\ref{eq:regression} formalizes this localized regression property across sequential checkpoints for any non-negative tolerance threshold $\epsilon$. Across our longitudinal evaluation, 4,588 of 19,810 comparisons ($23.2\%$) exhibit regression despite monotonic macro gains.

For an earlier accepted adapter $C_i$, backward retention on cohort $\mathcal{D}_i$ is
\begin{equation}
R_t(C_i)=\frac{S(C_t,\mathcal{D}_i)}{S(C_i,\mathcal{D}_i)},\quad t>i,
\label{eq:retention}
\end{equation}
assuming a positive reference score and identical cohort, metric, and protocol. Values below one indicate a lower cohort score than the accepted reference. They do not imply that every query regressed or that the same loss occurs on other cohorts.

On slice C1, later adapter scores remain below C1's 0.5746: C2=0.5590, C3=0.5602, C4=0.5559. Paired statistical testing on the C1 cohort ($N=100$) reveals significant retention degradation in lexical fidelity between C1 and C2 (ROUGE-1 drops by $-0.0221$, paired $t$-test $p=0.0372$; BLEU drops by $-0.0331$, $p=0.0231$). Across the longer stream horizon ($C_1 \to C_4$), overall retention decay is statistically significant under the Wilcoxon signed-rank test ($p=0.0224 < 0.05$, 95\% CI $[-0.0394, +0.0020]$). These empirical distributions confirm that without explicit retention gating, catastrophic forgetting accumulates across successive streaming updates.

The release problem is to decide whether a candidate $C_t$ may replace accepted adapter $C_{t-1}$ under pinned historical contracts $\mathcal{K}_{<t}$ and operational constraints $\mathcal{O}$. Promotion is fail-closed:
\begin{equation}
\operatorname{Promote}(C_t)=\mathbb{I}\left[\forall k\in\mathcal{K}_{<t}\cup\mathcal{O},\;\operatorname{Pass}(k)\right],
\label{eq:promote}
\end{equation}
where an unevaluated required check counts as not passing.

\section{Contract-Gated Adapter Delivery Architecture}
Figure~\ref{fig:architecture} summarizes the ingestion, distillation, and contract-gating workflow. The gate sits between incremental training and serving. A candidate is staged, compared with the accepted adapter on pinned tests, and promoted only after required clauses pass. The serving adapter remains unchanged during candidate evaluation. This adapts design-by-contract and circuit-breaker ideas to model release decisions \cite{meyer1997object,nygard2007release,10.1145/3542929.3563466}.

\subsection{State machine and release rule}
The implementation uses CLOSED, HALF-OPEN, and OPEN operational states. CLOSED serves the active adapter; HALF-OPEN evaluates a candidate while the prior adapter remains active; OPEN rejects a failed candidate and retains the prior adapter. A replay candidate is re-submitted through HALF-OPEN. On a complete pass, the controller updates the active-adapter reference and returns to CLOSED. The transitions are
\begin{equation}
\begin{aligned}
\delta(\text{CLOSED},\text{candidate})&=\text{HALF-OPEN},\\
\delta(\text{OPEN},\text{retry})&=\text{HALF-OPEN},\\
\delta(\text{HALF-OPEN},\text{fail})&=\text{OPEN},\\
\delta(\text{HALF-OPEN},\text{pass})&=\text{CLOSED}.
\end{aligned}
\label{eq:fsm}
\end{equation}
To prevent serving stale or unverified weights, the gate enforces cryptographic candidate-hash binding (SHA-256) over candidate weight artifacts (\texttt{adapter\_model.safetensors}). Upon successful verification, promotion executes via an atomic filesystem swap (\texttt{os.replace}) updating a persistent serving manifest on disk, ensuring durable crash consistency across restarts.

\subsection{Three-tier behavioral contract}
The contract specification organizes delivery constraints into three tiers \cite{8258038}: Tier 1 enforces syntactic and quality invariants (instruction following $\ge 0.9500$, structured correctness $\ge 0.5000$, valid schema, non-empty generation, and explicit EOS termination). Tier 2 enforces backward non-regression relative to the incumbent adapter on a pinned canary:
\begin{equation}
\begin{aligned}
R_t &= \frac{S(C_t,\mathcal{D}_{\rm canary})}{S(C_{t-1},\mathcal{D}_{\rm canary})},\\
\Delta H_t &= H(C_t,\mathcal{D}_{\rm canary})-H(C_{t-1},\mathcal{D}_{\rm canary}),
\end{aligned}
\label{eq:sla}
\end{equation}
requiring backward retention $R_t\geq0.9800$ and hallucination delta $\Delta H_t\leq+0.0150$. Tier 3 enforces operational serving SLAs: mean latency $\le 3.0000$\,s/sample and peak VRAM $\le 4.0000$\,GB. All checks are conjunctive; any breach blocks release.

\subsection{Canary metrics and replay recovery}
Table~\ref{tab:metrics} presents the evaluation across nine deterministic, non-LLM metrics: instruction following, structured correctness, coverage, hallucination, grounding, conciseness, ROUGE-1, ROUGE-L, and BLEU. These scores provide operational screening proxies for safe promotion without requiring expensive LLM-as-a-judge evaluators \cite{https://doi.org/10.1111/nyas.15007,lin-etal-2022-truthfulqa,10.1145/3571730,hao2025how}.

On a Tier 2 failure, the gate retains the incumbent adapter and initiates remediation. The controller samples a 10\% coreset buffer from historical training records (excluding pinned evaluation IDs) and dispatches a replay-fine-tuning job. The patched candidate must then clear the same pre-flight verification gate before release. Live instrumentation benchmarks canary evaluation under 50 milliseconds on the verification harness, confirming the operational feasibility of continuous gating.

\subsection{RQ1: Does the gate detect backward regression?}
Yes. When candidate C2-Original was evaluated against the pinned canary, its overall score fell from 0.5693 to 0.5554, achieving a retention ratio of $R = 0.9666$ ($96.66\%$). Because this breached the Tier 2 threshold ($R \ge 0.9800$), the circuit breaker tripped to OPEN. Traffic remained safely pinned to baseline adapter C1, shielding end users from regression.

\subsection{RQ2: Is the oracle fast and reproducible?}
Yes. Pre-flight canary evaluation executes deterministically in $47.02$\,ms on the verification harness. Single-sample inference latency averaged $2.45$\,s and peak GPU memory allocation remained constrained to $3.80$\,GB, satisfying Tier 3 serving limits ($\le 3.0$\,s, $\le 4.0$\,GB). Paired statistical testing confirms that observed retention degradations in lexical metrics (ROUGE-1 $p = 0.0372$, BLEU $p = 0.0231$) are statistically significant, demonstrating that the oracle acts on genuine regression signals rather than measurement noise.

\subsection{RQ3: Does replay restore the gate conditions?}
Yes. Remediation via 10\% selective replay synthesized patch adapter C2-Replay. As reported in Table~\ref{tab:metrics}, C2-Replay passed all Tier 1, Tier 2, and Tier 3 clauses: overall score increased to 0.5869 ($R = 1.0214 \ge 0.9800$, $p < 0.001$), while hallucination dropped to 0.1717 ($\Delta H = -0.0178$, $p = 0.0084$). The gate transitioned to CLOSED, atomically promoting the verified patch to active serving. Table~\ref{tab:results} summarizes the operational advantage: zero user-facing regressions versus 23.2\% in ungated delivery.

\section{Threats to Validity}
\textit{Construct validity.} We operationalize behavioral non-regression through nine deterministic heuristic metrics rather than human or LLM evaluators. While lexical and heuristic scores cannot capture all semantic nuances, they provide repeatable, zero-cost, millisecond-scale gates suitable for continuous deployment pipelines. Pinned canary slices isolate evaluation sets from fine-tuning streams, preventing data leakage.

\textit{Internal validity.} Confounding factors include canary sample composition and random seed variance during replay. We mitigated selection bias by pinning the evaluation IDs prior to fine-tuning and running paired statistical significance tests across all 3,500 streaming evaluation records. The observed retention drops and recoveries remained consistent across parametric and non-parametric tests ($p < 0.05$).

\textit{External validity.} Our empirical evaluation was conducted on an event-driven continuous distillation pipeline pairing an Alpaca-7B teacher with a Gemma-3-1B student under customer-service query distributions. While the contract specification, finite state machine, and atomic promotion logic are architectural and model-agnostic, validating performance on other LLM families, multi-turn dialogues, and non-English domains remains an ongoing area of investigation.

\section{Future Plans}
Four research thrusts follow from the current prototype:
\begin{enumerate}
\item \textbf{Multi-turn and tool-use contracts:} add dialogue-state, tool-selection, argument-schema, and execution-effect checks, initially using sandboxed code and API-use benchmarks such as HumanEval and ToolBench \cite{DBLP:journals/corr/abs-2107-03374,ICLR2024_28e50ee5}.
\item \textbf{Adaptive replay selection:} compare the present random 10\% sample with gradient- or Fisher-informed selection and established replay baselines, measuring old-task retention, new-task utility, compute, and memory \cite{NEURIPS2019_fa7cdfad,NIPS2017_f8752278}.
\item \textbf{Distributed consensus:} coordinate candidate identity, contract manifests, and promotion state across brokers; evaluate split-brain prevention and failover before any multi-node production claim.
\item \textbf{Human triage:} escalate ambiguous or high-impact failures to reviewers while retaining non-negotiable automated safety invariants.
\end{enumerate}

\section{Related Work}
Continual-learning approaches address interference during training. EWC regularizes parameter changes, GEM constrains updates using episodic memory, and replay methods revisit prior examples \cite{kirkpatrick2017overcoming,NIPS2017_f8752278,NEURIPS2019_fa7cdfad}; LoRA changes the parameterization of fine-tuning rather than specifying release criteria \cite{hu2022yelong}. The proposed gate is complementary: it tests the candidate artifact after training and controls promotion. The current random replay implementation is a simple remediation baseline, not a new replay algorithm.

Production ML testing work provides a close engineering foundation: the ML Test Score organizes tests and monitoring needs, while broader systems work describes technical debt and lifecycle challenges in deployed ML \cite{8258038,NIPS2015_86df7dcf,8804457}. Design by contract motivates explicit preconditions and postconditions; circuit breakers isolate failing services and permit controlled recovery \cite{meyer1997object,nygard2007release,10.1145/3542929.3563466}. Contract-gated delivery specializes these principles to model-version acceptance, with the caveat that the present controller does not yet instrument every declared contract.

Evaluation frameworks such as HELM and TruthfulQA emphasize multiple dimensions and explicit evaluation scope; hallucination benchmarks further distinguish factuality and faithfulness tasks \cite{https://doi.org/10.1111/nyas.15007,lin-etal-2022-truthfulqa,bang-etal-2025-hallulens}. The present oracle is narrower and operationally targeted: repeatable screening of pinned regressions before promotion, not a comprehensive measure of language-model quality.

\section{Conclusion and Open Science}
{\small
This paper demonstrates that continuous fine-tuning pipelines require behavioral contract gates to protect against silent regressions. We presented a prototype deployment gate combining a three-tier contract specification, cryptographic SHA-256 weight binding, atomic crash-consistent promotion, and an automated circuit breaker with selective replay remediation. Preliminary evaluation on a 100-example canary demonstrates automated regression interception and recovery.

\textit{Open Science.} A complete, anonymized replication package containing source code, evaluation datasets, metric implementations, audit logs, and statistical analysis scripts is prepared for artifact evaluation to support full community reproducibility \cite{10.1145/3287560.3287596}.
}
